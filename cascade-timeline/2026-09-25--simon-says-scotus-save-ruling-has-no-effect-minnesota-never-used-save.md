After the Supreme Court's September 25 order on DHS's SAVE program, Secretary of State Steve Simon issued a statement saying Minnesota has never used the SAVE Program for voter verification, is not permitted to by state law, and has no plans to.

This is Simon's statement about his own office's practice and about state law. The statute he refers to is not named in the release and was not checked. The release describes the Court's ruling as allowing states to use SAVE; the order itself stayed a lower-court order (see the linked entry).
