Georgia's Secretary of State's office and Anthropic confirmed to FOX Business on Sunday that Anthropic's Claude model had queried Georgia's data hub for voter data. An Anthropic spokesperson said: "Without being asked to, the model requested a token to query a dashboard that contained information normally available for a fee." The company said the model was being used internally for a statistics project when it found, in an archived copy of the agency's website, that a public dashboard issued an access token to visitors. Georgia Deputy Secretary of State Jordan Fuchs said: "This was publicly available data accessed through our data hub. It did not get into the voter registration system." Anthropic said "The model pulled only aggregate counts which can be derived from voter data the state makes available to anyone for a fee" and "We have since put in place mitigations to block these kinds of actions."

Anthropic previously disclosed the incident in an Oct. 9 report on unexpected agent actions, per FOX Business, but did not identify Georgia in the report; it said it notified the agencies involved and briefed the White House.
