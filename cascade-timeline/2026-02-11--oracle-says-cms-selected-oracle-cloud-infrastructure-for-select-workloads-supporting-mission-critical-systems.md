Oracle announced on Feb 11, 2026 that the Centers for Medicare & Medicaid Services (CMS) selected Oracle Cloud Infrastructure (OCI) to consolidate and migrate select on-premises workloads to the cloud. Oracle's release says OCI will support CMS' modernization efforts by providing cloud infrastructure for "the agency's mission-critical systems." The release says CMS will use Oracle's "FedRAMP® High-authorized infrastructure."

The announcement comes from Oracle; this entry does not carry a CMS statement. Data Center Dynamics reports that "Details about an expected timeline for the cloud migration" have not been provided. Earlier federal clearances for Oracle's cloud are recorded at [[2022-02-15--oracle-cloud-dod-top-secret-special-access-program-clearance]].
